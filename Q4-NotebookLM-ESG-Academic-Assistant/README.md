# Q4 — NotebookLM ESG Academic Assistant

## Objective
This experiment evaluates Google NotebookLM as an academic assistant for learning about sustainability reporting and the UN Sustainable Development Goals (SDGs).

## Experiments

### 1. Summarisation
NotebookLM summarised the UN 2030 Agenda, the 17 SDGs, sustainability reporting, standards, greenwashing, transparency, accountability and connections among environmental, social and economic issues. The source set was useful for an overview but did not comprehensively cover corporate ESG metrics or financial ESG evaluation models.

### 2. Quiz generation
NotebookLM generated a ten-question multiple-choice quiz. The recorded score was **9/10 (90%)**. The revised GRI Universal Standards were **published in October 2021** and became **effective for reporting from 1 January 2023**. This distinction should be retained because generated quiz feedback should be checked against the original source.

### 3. Mind map
A mind map titled “Sustainability Mind Map” used “Sustainability Reporting & Global Goals” as the central theme, with branches for GRI and UN SDGs. It gave a high-level overview but did not deeply map individual GRI disclosures to specific SDG targets.

### 4. Audio Overview
An Audio Overview titled “How Companies Track Sustainability Impact” was generated and played. Its duration was approximately 1 minute 27 seconds. It offered another review format, but its claims were not independently validated in full.

## Evaluation
NotebookLM was useful for summarising sources, generating self-test questions, organising concepts visually and creating audio. Limitations included dependence on source coverage, possible omissions in summaries, potentially incorrect quiz feedback, simplified mind-map relationships and audio claims that require verification. The tool is best used as a learning aid alongside original sources.
